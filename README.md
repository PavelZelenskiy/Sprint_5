Тебе предстоит написать автотесты для сервиса Stellar Burgers. Это космический фастфуд: можно собрать и заказать бургер из необычных ингредиентов.

Задание

Подготовь проект. Создай в IDE новый проект. Назови его Sprint_5. Подключи Selenium. Добавь файл .gitignore, чтобы в проект не попало ничего лишнего.

Изучи функциональность, которую нужно проверить. Что нужно проверить

Регистрация Проверь: Успешную регистрацию. Поле «Имя» должно быть не пустым; в поле Email введён email в формате логин@домен: например, 123@ya.ru. Минимальный пароль — шесть символов. Ошибку для некорректного пароля.

Вход Проверь: вход по кнопке «Войти в аккаунт» на главной, вход через кнопку «Личный кабинет», вход через кнопку в форме регистрации, вход через кнопку в форме восстановления пароля.

Переход в личный кабинет Проверь переход по клику на «Личный кабинет».

Переход из личного кабинета в конструктор Проверь переход по клику на «Конструктор» и на логотип Stellar Burgers.

Выход из аккаунта Проверь выход по кнопке «Выйти» в личном кабинете.

Раздел «Конструктор» Проверь, что работают переходы к разделам: «Булки», «Соусы», «Начинки».

❗️ Для регистрации используй почту в формате: имя_фамилия_номер когорты_любые 3 цифры@домен. Например, testtestov1999@yandex.ru. Это нужно, чтобы зарегистрироваться с уникальной почтой.

Определи и опиши локаторы, которые будешь использовать в тестах. Создай файл, в котором сохранишь описание элементов. Добавь к каждому локатору комментарий, чтобы было проще ориентироваться в них. Например:
... # Заголовок страницы ... # Кнопка «Войти» Названия должны быть понятными, чтобы с ними было удобно работать.

Напиши тесты на Selenium. Проверь, что тесты запускаются. Они должны проходить хотя бы в одном браузере. Нужно отправить тесты на ревью с подключённым Google Chrome. Каждый тест должен быть автономен. Это значит, он открывает страницу в браузере, выполняет свою задачу и закрывает браузер. Используй команду driver.quit() в конце каждого теста. Отчёт о тестировании не нужен.
Убедись, что файлы проекта организованы правильно. Вот небольшой чек-лист: Все тесты → в директории tests. Тесты на одну функциональность → в одном файле. Все фикстуры → в одном файле. README.md → в корневой директории. В нём есть описание проекта. .gitignore → в корневой директории. В нём названия всех файлов и папок, которые не нужно коммитить. Напиши функцию, которая генерирует логины. Помни что логин это email. Подключи генераторы логина и пароля к тестам.

Список файлов в проекте:

main dir:
    creds_randomizer - функции создания уникальных значений для переменных name, email, password
    locators - список локаторов для тестирования
    data - данные для авторизации зарегистрированного пользователя
    urls - список url адресов
    tests dir:
        test_constructor_tabs - набор тестов для проверки переходов между разделами конструктора
        test_login - набор тестов для проверки функции входа
        test_logout - набор тестов для проверки выхода их аккаунта пользователя
        test_personal_account_transition - набор тестов для проверки переходов в аккаунт пользователя
        test_registration - набор тестов для проверки функции регистрации пользователя
        test_transition_from_personal_account - набор тестов для проверки переходов из аккаунта пользователя

Запуск всех тестов производится через консоль командой pytest из корневой директории
Запуск определенного теста производится через консоль командой pytest tests/'название файла.py' из корневой директории
